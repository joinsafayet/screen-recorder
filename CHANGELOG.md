# Release notes

## 3.0.1 — Studio identity and repository release

- Folded P logo, navy macOS app icon, and 30 optical native vector icons across the studio, library, and editor.
- Branded About panel with version/build details and links to the project and downloads.
- Safer quit behavior: active edited exports/library updates finish or cancel first; queued exports pause and their state flushes before termination.
- Self-contained interface preview host with generated sample media, plus dark/light repository previews.
- Downloadable development app package and SHA-256 checksum; repository guide, issue/PR templates, and macOS build/media CI.

This is a locally signed Apple Silicon development preview. Signing/notarization and the remaining physical-device/unlocked capture checks are tracked in the verification guide.

## 3.0.0 — Recording studio and timeline

- Resizable studio/sidebar/inspector and refined dark/light/system themes with four accents.
- Native source picker, movable/resizable capture areas, aspect constraints, and saved regions.
- Live preparation preview, actual audio meters, output/storage estimates, and five-second test takes.
- Interrupted-session journals and recoverable movie fragments.
- Saved timelines with cuts, crop/aspect, zoom keyframes, audio fades, and undo/redo.
- Editable presentation overlays, cursor spotlight, modified-shortcut capture, manual/on-device captions, and SRT export.
- Projects, tags, batch actions, output presets, and a persistent export queue.

## 2.1 — Initial studio baseline

Display/window/area recording, audio mixing, presenter bubble, markers, pause/resume, capture telemetry, trim/export, recovery indexing, global shortcuts, and local libraries.
